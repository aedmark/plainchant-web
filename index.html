1.

01 The idea

One page, two ways to edit it

Most visual editors keep their own copy of your page and rewrite your files when you save. Plainchant Web does not. The Stage is a live view of your code, and every change you make on it edits only the exact characters it touches. Your formatting, comments and the rest of the file stay as you wrote them.

Click the paragraph and its code is highlighted. Double-click the text and type, and only that text changes in the file. Every page, stylesheet and script in your project is an ordinary file you can open anywhere else.

2.

02 How to

Six steps from nothing to a finished page

Open the Studio and follow along. Press F1 at any time for the guide and a list of every keyboard shortcut.

01

File › Open folder…

Open something. Open folder turns a folder into a project, Open file opens a single page, and Open project reopens one from your library. A folder is always one project: opening it again takes you back to the same one. Or just load the starter template.

02

Ctrl/Cmd+Shift+1 2 3

Choose a view. Code is the editor alone, Split shows the code beside the Stage, and Design is the Stage alone. Switch whenever the job changes.

03

Click · double-click · drag

Edit on the Stage. Click to select and see the code. Double-click text to rewrite it. Drag to reorder. The Inspector edits attributes and styles: flex and grid gap handles, pseudo-states like :hover, and a breakpoint switcher for @media rules.

04

Insert › drag onto the Stage

Add things fast. Drag an item from Insert onto the Stage and a guide shows where it will land. In the editor, type shorthand like section.hero or ul*3 and press Tab.

05

Problems tab · Alt+Shift+F

Check and tidy. The Problems tab finds broken links, missing images, missing alt text, skipped headings and unclosed tags across the whole project. Format re-indents the open file, and Find in project searches and replaces everywhere.

06

File › Preview… · Export…

Look, then ship. Preview opens the page in a real browser tab, and in the desktop app it can serve your project on your network so you can open it on a phone. Export writes your files back to a folder, or, in the browser, downloads them as a zip.

Safe by default

Your edits live in the Studio's own workspace. Nothing on your disk changes until you press Export, and Export never deletes a file. Everything is undoable with Ctrl/Cmd+Z.

3.

03 Features

Small enough to open in a second

Built for real sites with several pages, stylesheets and images, not just a single file.

The Stage
Design mode for editing, Live JS mode for running your scripts, phone and tablet widths, and a console that shows what your scripts print.
The Inspector
Attributes, a CSS Designer that edits the right rule in your stylesheet, box-model overlays, and an Assets browser for your images.
The Project
A file Explorer with folders you can collapse, drag to move and rename, with links updated for you. Shared page parts keep a header or footer in sync across pages.
The Checks
Links, accessibility and markup hints in one list. Click a problem to jump to the exact spot in the code.
The Keeper
Autosave, a project library, named versions you can return to, and undo and redo across every file and Stage action.
The Promise
It runs in your browser, works offline, and keeps your projects on your device. No account, no cloud lock-in, no tracking, and no runtime dependencies.
4.

04 Desktop

The same studio, with folder access

The browser version works anywhere. The desktop app (built with Tauri) adds a native folder picker, local images served straight from your folder, and the network preview for testing on a phone. Chromium browsers can open and export folders too.

One folder, one project

The Studio remembers which folder a project came from. Open the same folder again and you get your project back, with a Reload from disk button if the files changed outside the Studio.
