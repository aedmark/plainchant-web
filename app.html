Dreamweaver-Style Round-Trip Editing

Your index.html, styles.css, and script.js files are always the single source of truth. Every visual action on the Stage splices only the exact character range in your source code.

  • Select & Inspect: In Design Mode, click any element on the Stage to highlight it, view its ancestor path in the bottom Tag Selector bar, and edit its HTML attributes or CSS rules in the Inspector.
  • Inline Text Editing: Double-click any text element on the Stage to edit its copy directly in place. Press Enter or click away to commit the change as an undoable edit (Ctrl/Cmd+Z).
  • CSS Designer: Choose whether your style changes target a shared CSS selector in styles.css (like .card) or the element's inline style attribute.
  • Insert Bar & Shorthand: Click any button in the Insert toolbar to add semantic HTML5 blocks inside or after the selected element, or type shorthand like section.hero or ul*3 in the HTML editor and press Tab.
  • Live JS Mode: Switch the Stage from Design to Live JS to execute script.js and interact with your page normally.
  • Hybrid Desktop & Browser: Open and sync real project directories on disk via Tauri or the browser File System Access API using the Folder button.
